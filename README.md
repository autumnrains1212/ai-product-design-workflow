# AI产品设计与交付工作流

从一段需求开始，按本轮范围产出 **PRD、UI 设计、可运行原型和验证交接记录**。适合 AI 问答、内容生成、信息提取、工具执行及混合产品，也能继续已有项目或处理局部修改。

技能标识：`ai-experience-design` · 调用：`$ai-experience-design` · 版本见 [VERSION](VERSION)。

## 这次希望做到哪一步？

| 范围 | 主要产物 |
|---|---|
| 只写需求 | 可评审 PRD、事实与假设、功能和验收条件 |
| 只做设计 | 关键流程、适用状态、可编辑设计或交互原型 |
| 可运行实现 | 核心路径、必要集成、测试修复与交接 |

已有成果会先检查再复用。小改动只更新受影响的规则与验证，十二章需求模板按实际情况取用。

## 安装与开始

下载仓库后，按照[安装说明](01-安装说明.md)，将整个 `ai-experience-design/` 文件夹安装到当前 Codex 环境识别的技能目录。保留全部子目录，不能只复制 `SKILL.md`。首次使用可在新对话中发送：

```text
使用 $ai-experience-design 完成以下需求：
产品或想法：〔想做什么〕
目标用户：〔谁来使用〕
本次交付范围：〔PRD／设计原型／可运行实现〕
已有资料与限制：〔文件、设计、代码、平台或预算，没有可不填〕

先整理适用的需求规格，再按本次范围推进。
普通缺失信息记录为假设，关键目标或权限不明确时再询问。
交付实际成果位置、已执行的检查和剩余待办。
```

更多例子见[使用说明与指令模板](02-使用说明与指令模板.md)。

## 六种网页风格

| 风格 | 适合场景 |
|---|---|
| Ant · 企业后台 | 管理、审批、密集表格与表单 |
| Clean · 清爽工具 | 轻量工具、设置、上传转换 |
| Editorial · 编辑阅读 | 知识、报告、文章与长内容 |
| Friendly · 亲和消费 | 大众服务与新手引导 |
| Enterprise · 深色工作台 | 明确需要深色的监测、运维与云资源台 |
| Agentic · AI任务助手 | 多步委托、成果审阅与下一步决策 |

可直接指定“本次采用 Clean 风格”；未指定时按任务选择一种主风格。已有品牌和设计系统优先，纯需求文档与原生移动界面不套用网页视觉。详见[网页风格选择](04-网页风格选择.md)。

## 环境与来源

本仓库提供工作方法与资料，字体、模型服务、业务接口、组件库和设计工具账户由使用环境提供。文档、模拟、实际运行、模型质量和真人效果分别记录；发布、发送或付费等操作按明确授权执行。

示例均为通用说明，不代表真实项目记录。第三方风格保留原始署名与许可标记，未将整个仓库统一声明为 MIT。来源和版本说明见[来源与版本](03-来源与版本.md)。
