# 清爽工具 · Clean

用于轻量工具、表单、设置和一般 SaaS 网页，以清楚的任务与操作为中心。数据密集、长篇阅读或明确需要深色监控时，应按[风格选择规则](../web-style-selection.md)另选主风格。已有品牌与用户指定优先；仅写需求文档且不涉及界面设计，或原生移动任务不套用本页。文字版网页 UI 设计规格仍适用本风格。

## 来源基础

来自 typeui.sh、标注 MIT 的[技能原文](../../assets/style-sources/clean-skill.md)和[设计原文](../../assets/style-sources/clean-design.md)，不是某个官方组件库的默认配置。

- 基础色：主色 `#3B82F6`、次色 `#8B5CF6`、成功 `#16A34A`、警告 `#D97706`、危险 `#DC2626`、表面 `#FFFFFF`、正文 `#111827`。
- 字体：正文 Roboto，标题 Poppins，等宽 Inconsolata；字号 `12/14/16/20/24/32px`。源角色为标题 `2rem`、正文 `1rem`、标签 `0.75rem`；字重列为 100–900，仅选择实际可用的所需字重。
- 间距：8pt 基线，源小/中间距为 `8/16px`；圆角 `4/8px`。`neutral: #FFFFFF` 是兼容字段，边框、次级文字等中性色需在项目中补齐。

以上是参考原值。字体文件和组件实现未随包提供；中文使用项目或系统中可用的无衬线、等宽回退，检查混排。颜色按实际语义映射与前景/背景测量，不直接把主色配白字视作合格组合。

## 执行建议

以下是根据风格整理的实施建议：用页面标题、短说明、任务区和主操作建立层级；少量分组即可表达关系，不把每段内容装成卡片。区块间隔可按 8px 基线推导为 `24/32px` 并记录。表单以可关联标签、说明和字段错误表达规则；按钮或链接按真实动作选用语义元素。

文案直接说明动作与对象，例如“保存设置”；避免仅写“确定”。反馈应说明已知原因与可行下一步，不承诺未经验证的完成时限。

按功能检查默认、hover、focus-visible、active、disabled、loading、error 及空/成功状态；等待反馈与真实业务行为一致。长标签、错误和结果可换行；窄屏按内容重排操作，避免仅靠悬停暴露入口。来源建议触摸目标 44px 以上，实际验收按[网页共用规则](../web-ui-foundations.md)执行适用标准与例外。

避免用极浅文字制造“简洁”、用大留白隐藏重要操作，或给相邻组件随意配置不同间距。交付时核对语义色、已加载字体、间距、全部适用状态、键盘顺序、实际目标视口与长内容；分别记录设计、运行证据和未覆盖项，一次只采用一种主风格。
