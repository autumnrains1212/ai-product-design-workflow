# AI 会议整理 Skill V1

根据岗位和纪要用途整理会议草稿，保留关键原话，并标出需要人工核对的内容。

## 开始使用

1. 打开 [AI会议整理Skill_V1.md](AI会议整理Skill_V1.md)，复制全文到 AI 对话。
2. 提供纪要用途，可补充岗位、关注栏目和详细程度。
3. 粘贴会议转写，生成草稿后对照原话核对、修改并确认。

开场示例

```text
请按刚才的 Skill 整理以下会议内容。

我的岗位：UI/UX 设计师
纪要用途：正式会议纪要
关注重点：设计评审结论、需要修改的内容、设计交付事项、待确认问题
详细程度：详细

【会议转写】
在这里粘贴会议文字。
```
